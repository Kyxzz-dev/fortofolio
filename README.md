# Modern Portfolio by Rahmad Rifky Alfaresh

- **Website**: [porto-rxyz.vercel.app](https://porto-rxyz.vercel.app)
- **Tech Stack**: Next.js 16, React 19, TypeScript, Tailwind CSS v4, Framer Motion

## Features
- Dynamic dark aesthetics with smooth glow effects and micro-interactions
- Responsive design tailored for all screen sizes
- Clean, modular, and configurable data architecture

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev
```
